# rzg002-releases

Kanal rilis **Peternak Bebek Simulator** (RZG-002, RizogLabs).

Repo ini hanya berisi APK rilis resmi di tab **Releases** — tidak ada kode sumber di sini.

Update otomatis di Android: pasang **Obtainium**, tambahkan repo ini sebagai sumber aplikasi, lalu pasang game lewat Obtainium. Rilis berikutnya akan terpasang sendiri (unduhan disarankan hanya lewat Wi-Fi).
